# QuAgentic

Motivation: After a talk from Yuri Alexeev at the NCSU Quantum Workshop. I have an inspiration on building AI agents to help me discover and boost my productivity as a researcher.  

Therefore, this repository will help me, and likely to more people, to get a practical in combining quantum research with agents. My idea is to build a completely workflow that will speed up my research and understanding of this. 

## Implementations to perform:
-  Agent for efficient Block Encodings. 
-  Agent for finding practical problems and been solvable using near-term hardware.
